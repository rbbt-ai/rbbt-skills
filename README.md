# Rbbt Skills

Biblioteca de skills reutilizáveis da Rbbt AI para agentes de desenvolvimento.

## Skills disponíveis

- [`frontend-design`](skills/frontend-design/SKILL.md): criação de interfaces web distintas e prontas para produção.

## Instalação

```bash
git clone git@github.com:rbbt-ai/rbbt-skills.git
cp -R rbbt-skills/skills/frontend-design ~/.codex/skills/frontend-design
```

Cada skill mantém sua licença e suas instruções em `SKILL.md`.
